# 📊 Análisis de Ventas con PostgreSQL y Power BI

Proyecto de análisis de datos realizado sobre una base de datos de **más de 120.000 registros**, utilizando **PostgreSQL** para el análisis y **Power BI** para la visualización de los resultados.

Este proyecto también representa mi primer análisis utilizando PostgreSQL, después de haber trabajado anteriormente con **MySQL**. El objetivo fue aplicar los conocimientos adquiridos sobre PostgreSQL a un conjunto de datos de ventas y posteriormente conectar los resultados con Power BI para construir un dashboard interactivo.

## 🛠️ Herramientas utilizadas

* **PostgreSQL** — Consulta y análisis de datos
* **Power BI** — Visualización y creación del dashboard
* **CSV** — Fuente de datos
* **SQL** — Consultas, agrupaciones, funciones de agregación y análisis

## 🔎 Análisis realizado

El proyecto busca responder las siguientes preguntas de negocio:

1. ¿Cuál es el total de ingresos por ventas de cada producto?
2. ¿Cuánto dinero se ha vendido en total por cada ciudad?
3. ¿Cuáles son los productos con mayor cantidad de unidades vendidas?
4. ¿Cuál es el monto total de ventas logrado por cada vendedor?
5. ¿Cuántas ventas se han registrado con cada método de pago?
6. ¿Cuál es el total de ventas mensuales a lo largo del tiempo?
7. ¿Qué productos generan el mayor ingreso promedio por transacción?
8. ¿Cuánto ingreso se obtuvo por cada categoría de producto?
9. ¿Cuáles son los productos más vendidos en cantidad por cada ciudad?
10. ¿Cuánto vendió cada vendedor en cada ciudad específica?
11. ¿Cuál es el precio unitario promedio de cada producto?
12. ¿Cuántas ventas se realizaron en cada año registrado?

## 📈 Dashboard

Después de realizar el análisis en PostgreSQL, la información fue conectada a **Power BI** para crear un dashboard que permite visualizar los principales resultados del conjunto de datos.

Las imágenes incluidas en la carpeta `imagenes/` permiten consultar el resultado del dashboard incluso cuando el archivo de Power BI no puede abrirse.
